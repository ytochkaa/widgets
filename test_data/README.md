# Тестирование

Базы `.sqlite` взяты из архива `InputData.rar` к заданию, файлы `.json` сгенерированы самостоятельно.
В папке `invalid` лежат некорректные файлы для проверки обработки ошибок.

## Пользовательские тест-кейсы

### Case №1
**Проверка запуска приложения**

Входные параметры: -

- Шаг 1 — запустить приложение `./widgets`

Результат: открывается главное окно: слева кнопка «Открыть папку» и список файлов домашней папки, справа настройки и пустая область графика; в статус-баре надпись «Выберите файл БД»

---

### Case №2
**Проверка выбора папки**

Входные параметры: папка `test_data`

- Шаг 1 — нажать «Открыть папку»
- Шаг 2 — выбрать папку `test_data`

Результат: в списке слева отображаются файлы `.sqlite` и `.json` из папки `test_data`

---

### Case №3
**Проверка построения графика из SQLite**

Входные параметры: файл `test_data/HUMIDITY_MOSCOW.sqlite`

- Шаг 1 — открыть папку `test_data`
- Шаг 2 — выбрать в списке `HUMIDITY_MOSCOW.sqlite`

Результат: строится столбчатая диаграмма из 10 столбиков; в статус-баре — `Файл: HUMIDITY_MOSCOW.sqlite, точек: 1438`

---

### Case №4
**Проверка построения графика из JSON**

Входные параметры: файл `test_data/MONTHLY_TEMPERATURE.json`

- Шаг 1 — открыть папку `test_data`
- Шаг 2 — выбрать в списке `MONTHLY_TEMPERATURE.json`

Результат: строится график из 12 точек; в статус-баре — `Файл: MONTHLY_TEMPERATURE.json, точек: 12`

---

### Case №5
**Проверка большого файла**

Входные параметры: файл `test_data/NORDPOOL_PRICES.sqlite` (89 764 точки)

- Шаг 1 — выбрать в списке `NORDPOOL_PRICES.sqlite`

Результат: график строится, столбчатая диаграмма содержит 10 столбиков (точки усреднены), приложение не зависает

---

### Case №6
**Проверка смены типа графика**

Входные параметры: построен график из Case №3

- Шаг 1 — выбрать в списке «Выберите тип диаграммы» пункт `PieChart`
- Шаг 2 — выбрать пункт `LineChart`
- Шаг 3 — выбрать пункт `BarChart`

Результат: график перестраивается под выбранный тип из тех же данных, файл повторно не загружается

---

### Case №7
**Проверка чёрно-белого стиля**

Входные параметры: построен график из Case №3

- Шаг 1 — поставить галочку «Черно-белый график»
- Шаг 2 — снять галочку

Результат: при включённой галочке график рисуется оттенками серого, при выключенной — снова цветной

---

### Case №8
**Проверка печати графика в PDF**

Входные параметры: построен график

- Шаг 1 — нажать «Печать графика»
- Шаг 2 — выбрать место сохранения и имя файла, нажать «Сохранить»

Результат: по указанному пути создаётся PDF-файл с текущим графиком; в статус-баре — `График сохранён: <путь>`

---

### Case №9
**Проверка печати в чёрно-белом стиле**

Входные параметры: построен график, стоит галочка «Черно-белый график»

- Шаг 1 — нажать «Печать графика» и сохранить файл

Результат: в PDF график напечатан оттенками серого

---

### Case №10
**Проверка печати без данных**

Входные параметры: файл ещё не выбран

- Шаг 1 — запустить приложение
- Шаг 2 — нажать «Печать графика»

Результат: диалог сохранения не открывается; в статус-баре — `Сначала выберите файл с данными`

---

### Case №11
**Проверка неподдерживаемого формата**

Входные параметры: файл `test_data/invalid/notes.txt`

- Шаг 1 — открыть папку `test_data/invalid`
- Шаг 2 — выбрать `notes.txt`

Результат: график не меняется; в статус-баре — `Формат не поддерживается: notes.txt`

---

### Case №12
**Проверка JSON с синтаксической ошибкой**

Входные параметры: файл `test_data/invalid/broken_syntax.json`

- Шаг 1 — выбрать `broken_syntax.json`

Результат: приложение не завершается, ранее построенный график сохраняется; в статус-баре — `Не удалось прочитать данные из broken_syntax.json`; в консоли — `[ERROR] Ошибка в JSON ...`

---

### Case №13
**Проверка JSON неверной структуры**

Входные параметры: файл `test_data/invalid/not_array.json` (объект вместо массива)

- Шаг 1 — выбрать `not_array.json`

Результат: в консоли — `[ERROR] JSON должен быть массивом точек`; приложение продолжает работу

---

### Case №14
**Проверка JSON с нечисловым значением**

Входные параметры: файл `test_data/invalid/bad_value.json` (в поле `value` строка)

- Шаг 1 — выбрать `bad_value.json`

Результат: в консоли — `[ERROR] Неверная точка №1 ...`; приложение продолжает работу

---

### Case №15
**Проверка пустого файла**

Входные параметры: файл `test_data/invalid/empty.json` (нулевой размер)

- Шаг 1 — выбрать `empty.json`

Результат: в консоли — `[ERROR] Ошибка в JSON ...`; приложение не завершается

---

### Case №16
**Проверка файла, не являющегося базой SQLite**

Входные параметры: файл `test_data/invalid/not_a_database.sqlite` (текст с расширением `.sqlite`)

- Шаг 1 — выбрать `not_a_database.sqlite`

Результат: в консоли — `[ERROR] В базе нет таблиц или это не база SQLite`; приложение продолжает работу
